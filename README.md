# Причудливая Жизнь

Фанатская 3D-игра по мотивам JoJo's Bizarre Adventure. Создаёшь своего персонажа, живёшь обычной жизнью в огромном мире — а судьба тем временем случайно выбирает, какие причудливые истории с тобой случатся.

Работает прямо в браузере, без установки. Движок — Three.js (лежит в `vendor/`, поэтому игра запускается и без интернета).

## Как запустить

Открой `index.html` в браузере (Chrome, Edge, Firefox, Safari). Можно и через локальный сервер:

```
npx serve .
```

Чтобы собрать игру в один HTML-файл (Three.js тогда грузится с CDN):

```
node tools/build-single.mjs
```

## Что есть в игре

**Персонаж.** Имя, пол, 8 причёсок (помпадур, фуражка Джотаро, три завитка Джорно…), цвета кожи, волос и одежды, 6 характеристик и 9 происхождений — от школьника из Морио и наследника Джостаров до потомка Брандо и прирождённого стенд-юзера.

**Огромный мир** — 1536 × 1152 клеток, 18 регионов: Морио-тё, Неаполь, Рим, Венеция, Лондон, Швейцарские Альпы, Каир, Тибет, Варанаси, Сингапур, Нью-Йорк, Сан-Диего, пустыня Аризоны, Флорида, Мексика, Аравийская пустыня, ледяной перешеек и остров Эйр-Сапплена. Мир генерируется заново для каждой новой жизни. Города соединены дорогами и мостами, между ними можно ходить пешком, ездить верхом или путешествовать с вокзалов. Смена дня и ночи, погода (дождь, снег, песчаные бури, туман).

**Обычная жизнь.** Сытость и бодрость, сон, еда (у каждой страны своя кухня), работа (кассир, официант, грузчик, клерк, археолог, ассистент Рохана, поручения Пассионе…), учёба, спортзал, отели, казино, больницы, магазины и чёрный рынок. Задания в барах и полиции: доставка, потерявшийся кот, охота за головой, гнёзда вампиров, бои на арене Колизея.

**Стенды — 78 штук** из частей 3–8, каждый со статами A–E, тремя способностями и уровнями. Эволюции: Эхо (акты 1→2→3), Бивень (акты 1→4), Белая Змея → Си-Мун → Made in Heaven, Звёздная Платина → Мир, Реквиемы через Стрелу (Золотой Опыт, Серебряная Колесница), Bites the Dust, Поезд Любви. Без своего стенда чужие стенды и их атаки не видны.

**Как получить стенд:** Стрела (шанс выжить зависит от Духа и происхождения), стенд-диски (Белая Змея ворует их у врагов), части Святого Трупа, Дьявольская ладонь, испытание Польпо, Кейчо Нидзимура, чёрный рынок, слухи о сокровищах.

**Хамон** — у мастеров (барон Цеппели, Тонпетти, Лиза Лиза) через мини-игру дыхания. Хамон-удары, клакеры, Солнечный Жёлтый Овердрайв, ходьба по воде.
**Вампиризм** — Каменная маска: заморозка, лучи из глаз, питьё крови, регенерация; солнце сжигает.
**Вращение** — у Джайро Цеппели: стальные шары, лечение, Золотое вращение верхом.
**Совершенная форма жизни** — вампир + маска + Красный камень Айи.

**Случайный сюжет.** Шесть глав: «Несокрушимый Морио» (Кира), «Наследие ДИО», «Золотой Ветер» (Пассионе и Дьяволо), «Боевое Направление» (Люди из Столпа), «Каменный Океан» (Пуччи) и «Steel Ball Run» (Валентайн). Порядок и детали (улики, убежища, наёмники) каждый раз свои, плюс случайные события: засады стенд-юзеров, зомби по ночам, звери, слухи о Стрелах и масках.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение (относительно камеры) |
| Мышь | камера (клик — захват мыши; без захвата — тянуть правой кнопкой) |
| ЛКМ / ПКМ (или X) | удар / тяжёлый удар |
| Пробел / Shift | рывок / бег |
| G | призвать стенд |
| Q, E, R | способности стенда |
| 1, 2, 3 | приёмы хамона, вампира, вращения |
| V | дыхание хамона |
| T / H | сменить стиль / сесть на лошадь |
| F | говорить, войти в здание |
| I, P, C, L, M, K | инвентарь, персонаж, стенд, журнал, карта, стендопедия |
| Esc / F1 | меню и сохранение / помощь |

На телефоне — джойстик слева, кнопки справа, камера свайпом.

Сохранение — в браузере (меню или сон дома/в отеле).

Фанатский проект, не связан с правообладателями JoJo's Bizarre Adventure.
